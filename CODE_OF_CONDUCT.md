# Code of Conduct

This project adheres to the
[Qiskit Code of Conduct](https://github.com/Qiskit/qiskit/blob/main/CODE_OF_CONDUCT.md).

By participating — filing an issue, opening a pull request, or taking part
in any discussion here — you agree to uphold it.

Report unacceptable behaviour to the maintainer via a GitHub issue, or to
the Qiskit community team through the channels named in the linked
document.
